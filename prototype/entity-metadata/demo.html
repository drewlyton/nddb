What does a fetched record hand back?

nddb keeps a materialised view in memory and returns records from it. This demo asks one question: when you fetch a record and then edit it without saving, does the database change? Switch the connection style and run the same edit to feel the difference. The log at the bottom is the actual file and never changes unless you press save.
